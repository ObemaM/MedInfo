# История изменений проекта

Эта папка нужна для ручного ведения заметок по изменениям перед коммитами.

Как используем:

1. Перед коммитом просим Codex подготовить две версии описания:
   - короткое резюме для git commit message;
   - подробное резюме для markdown-файла в этой папке.
2. Для каждого осмысленного коммита создаем отдельный `.md` файл.
3. Имя файла держим в формате:

```text
YYYY-MM-DD-short-topic.md
```

Например:

```text
2026-04-29-update-local-project-paths.md
```

Что писать внутри:

- краткий контекст задачи;
- что изменилось в коде или документации;
- какие файлы/модули затронуты;
- что проверено;
- что осталось сделать или уточнить.

Шаблон лежит в [_template.md](./_template.md).
