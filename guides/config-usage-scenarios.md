# Сценарии использования настроек подключения

Этот файл фиксирует подтвержденные сценарии использования экрана настроек подключения.
Позже из него можно собрать раздел руководства пользователя.

## Что это за режим

Настройки подключения - это локальный сервисный режим устройства.

Он не является серверным аккаунтом и не выполняет вход в систему. После открытия этого режима приложение не сохраняет пользовательскую сессию и не запускает SignalR-сервис.

## Сценарий: открыть настройки подключения

Условия:

- пользователь находится на экране авторизации;
- приложение установлено на устройстве;
- экран авторизации доступен.

Шаги:

1. В поле `Логин` ввести `admin`.
2. В поле `Пароль` ввести `0000`.
3. Нажать `Войти`.

Ожидаемый результат:

- приложение не отправляет логин и пароль на сервер;
- открывается экран `Настройки подключения`;
- пользовательская сессия не создается;
- SignalR-сервис не запускается.

## Сценарий: изменить адрес сервера

Условия:

- пользователь открыл экран `Настройки подключения`.

Шаги:

1. В поле `Адрес сервера` ввести новый базовый адрес.
2. Проверить строку предпросмотра SignalR: она должна показывать адрес вида `{адрес сервера}/notifications`.
3. Нажать `Сохранить`.

Ожидаемый результат:

- адрес сохраняется во внутренний `config.json` приложения;
- Retrofit-клиент пересоздается с новым адресом;
- при следующей авторизации приложение использует новый сервер.

Правила ввода:

- адрес не должен быть пустым;
- адрес должен начинаться с `http://` или `https://`;
- завершающий `/` в конце адреса удаляется автоматически.

## Сценарий: изменить таймауты HTTP

Условия:

- пользователь открыл экран `Настройки подключения`.

Шаги:

1. В поле `Подключение, сек` ввести таймаут подключения.
2. В поле `Ответ, сек` ввести таймаут ожидания ответа.
3. Нажать `Сохранить`.

Ожидаемый результат:

- значения сохраняются;
- Retrofit-клиент пересоздается с новыми таймаутами.

Правила ввода:

- оба значения должны быть целыми числами от 1 до 120.

## Сценарий: изменить таймер принятия решения

Условия:

- пользователь открыл экран `Настройки подключения`.

Шаги:

1. В поле `Таймер принятия решения, минут` ввести длительность таймера.
2. Нажать `Сохранить`.

Ожидаемый результат:

- значение сохраняется в минутах;
- внутри конфига оно хранится в миллисекундах;
- новые входящие сценарии используют обновленную длительность.

Правила ввода:

- значение должно быть целым числом от 1 до 240.

## Сценарий: отключить SignalR для тестов

Условия:

- пользователь открыл экран `Настройки подключения`.

Шаги:

1. Включить переключатель `Отключить SignalR для тестов`.
2. Нажать `Сохранить`.

Ожидаемый результат:

- флаг сохраняется в конфиг;
- при следующем запуске SignalR-сервис не подключается к хабу, если тестовый режим включен.

## Сценарий: вернуть значения по умолчанию

Условия:

- пользователь открыл экран `Настройки подключения`.

Шаги:

1. Нажать `Вернуть значения по умолчанию`.
2. Проверить подставленные значения.
3. Нажать `Сохранить`, если нужно применить сброс.

Ожидаемый результат:

- кнопка сброса только заполняет форму значениями по умолчанию;
- конфиг меняется только после нажатия `Сохранить`.

## Сценарий: закрыть настройки без сохранения

Условия:

- пользователь открыл экран `Настройки подключения`.

Шаги:

1. Нажать `Закрыть`.

Ожидаемый результат:

- экран настроек закрывается;
- изменения, которые не были сохранены кнопкой `Сохранить`, не применяются.
